## Remaining Findings

### Critical: C2 still permits secrets through external evidence references

The new policy protects dictionary-keyed payloads, but `evidence_refs` is a separately persisted caller-controlled list and is written twice without validation. Constrain references to canonical local artifact IDs or explicitly validated non-secret reference envelopes before serialization. A constant error code should be returned without including the rejected reference.

### Important: I2 cleanup can force-delete a worktree not proven to belong to the caller

Containment and Git registration establish location, not ownership. This is especially dangerous because `git worktree remove --force` can discard uncommitted changes. Cleanup needs a durable ownership record and lock check; concurrent creation/removal and a foreign registered worktree under the configured root need regression tests.
