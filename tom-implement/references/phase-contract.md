# Implement Phase Contract

Input is the exact G4-approved task-plan envelope, owned worktrees, baseline revisions, and language/project rules. Output is a `change-set` envelope containing atomic business and independent product-test patches, complete diff, changed symbols, test IDs, traceability delta, and hashes. Persist to KU and comment iCafe through the parent; EvidenceGate and G5 approval precede Review. Stop on ownership, baseline, plan coverage, or hash mismatch. Mac only generates/inspects source; all execution belongs to iPipe.
